# Project Screenshots Folder

Drop your project screenshots here, then connect them to project cards in
`src/data/portfolio.js` like this:

```js
image: "images/projects/aleef.jpg",
```

Recommended: JPG or PNG, ~1200 × 800 px (16:10 or 4:3 landscape looks best).

Until an image is added, every project card automatically shows a styled
gradient cover with an icon — the site never looks broken or empty.

Full instructions: `docs/USER_MANUAL.md`, Chapter 3.
