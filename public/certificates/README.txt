YOUR CERTIFICATE FILES LIVE IN THIS FOLDER
==========================================

Supported file types: PDF, JPG, JPEG, PNG.

1. UPLOAD     Copy your certificate file into this folder
              (public/certificates/).

2. REGISTER   Open src/data/certificates.js and add one { ... } block:
              { id, name, organization, issueDate, category, file }
              Example file path:  "certificates/my-certificate.pdf"

3. DONE       Save, and the certificate appears on the website
              automatically — card, category filter, "View Certificate"
              preview and "Download Certificate" button.

The sample-*.pdf / sample-*.jpg / sample-*.png files here are clearly
labeled placeholders used to demonstrate the gallery. Replace or delete
them once your real certificates are in.

Full walkthrough: docs/USER_MANUAL.md — Chapter 4, Managing Certificates.
